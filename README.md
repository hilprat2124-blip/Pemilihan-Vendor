# Vendor Selection Dashboard

Prototipe Streamlit untuk seleksi vendor Project A — Piping Installation.

## Jalankan di komputer

1. Instal Python 3.10 atau lebih baru.
2. Buka terminal di folder proyek.
3. Jalankan:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. Buka URL lokal yang ditampilkan oleh Streamlit.

## Publikasi online

Unggah `app.py` dan `requirements.txt` ke repository GitHub, lalu deploy repository melalui Streamlit Community Cloud.

## Catatan

Data vendor adalah simulasi. Periksa persyaratan teknis, HSE, kontrak, dan prosedur procurement perusahaan sebelum menggunakan hasil untuk keputusan nyata.
